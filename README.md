##GB to MB/KB converter
This program can convert your GB file into a more useful format such as MB or KB allowing you to understand the scale of the file. This is a test edit to check a merge conflict.

##How to run the program
By downloading the .py file, you can execute the file, in the file you can make an input of the file in GB in the first line and recieve your data converted into MB and KB.
